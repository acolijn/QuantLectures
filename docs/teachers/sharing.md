# Sharing and access

Who can see a course is decided by two switches and by invite codes, all in
**⚙️ Course settings**.

## Visibility

| Setting | Who sees the course |
|---|---|
| Neither ticked | Only you and your co-editors. Shown as **Draft**. |
| **Published (visible to students)** | Students who joined with an invite code. |
| **Published** + **Publicly available (visible without sign-in)** | Anyone, also without an account. |

Work on a new course unpublished, and publish it when it is ready. A public
course does not need invite codes, but students only keep quiz progress when
they are signed in.

## Invite codes

Under **Student invite codes**:

1. Type a code that is easy to read out, for example `QM2026`.
2. Optionally set **Max uses** — useful against codes being passed around.
3. Click **Create code**.

Students sign in, click **Add a course** and enter the code. Or share a link
that fills it in for them:

```
https://minilectures.app/?invite=QM2026
```

The list shows each code with **Used: n/max**. **Revoke** stops a code from
working; students who already joined keep access.

::: tip
Teachers and administrators do not use invite codes — they get access as
co-editors.
:::

## Co-editors {#co-editors}

A course has one **Owner** (whoever created it) and any number of **Editors**.

- **Editors** can write, import, export and delete chapters.
- Only the **owner** can change course settings: visibility, invite codes,
  parts, editors, deleting the course.

To add an editor: **⚙️ Course settings** → **Members (editors)**, search for
your colleague by name or email, and click **Add editor**. They need a teacher
account first. **Remove** takes their access away again.
